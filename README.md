## About

LOGJAM is a mapping and logbook app designed for canyoning in New South Wales.

## Features

- Map of canyons in NSW
- Choose from several basemaps from OpenStreetMaps and SIX Maps
- Filter canyons by their attributes, or search by name

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Zen-TM/logjam.git
   ```

2. Switch to the `dev` branch:

   ```bash
   git checkout dev
   ```

3. Ensure you have Node.js and npm installed on your machine. You can download them from [Node.js official website](https://nodejs.org/).

4. Install dependencies:

   ```bash
   npm install
   ```

## Usage

To run the app locally, navigate to the project directory and use the following command:

```bash
npm run dev
```
